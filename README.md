## Cara Menjalankan Program

1. Buka Terminal atau Git Bash.
2. Masuk ke folder proyek.

```bash
cd nama-folder-proyek
```

3. Jalankan program Python.

Contoh:

```bash
python latihan/01_biodata.py
```

atau

```bash
python tugas/kalkulator_koordinat.py
```
